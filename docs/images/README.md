# Documentation Images

Commit workshop screenshots and diagrams here so they render in the guides and the
top-level `README.md`.

Images anywhere else in the repo are gitignored (`*.png`, `*.jpg`, `*.gif`); this folder
is explicitly allow-listed in `.gitignore` so files placed here **are** published.
